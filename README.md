# Algo Trading IBKR Dashboard

Personal trading dashboard with a reusable Python analysis engine, Express API, and Vite React frontend.

## Telegram Alerts

BUY alerts are generated by `python-engine/alerts.py` when scanner opportunities have:

- `signal == "BUY"`
- `opportunity_score >= 60`

Alerts are always saved locally to `python-engine/alerts.json`. Telegram notifications are disabled unless explicitly enabled.

### Setup

Add these values to `python-engine/.env`:

```env
TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id
SEND_ALERTS=true
```

Leave `SEND_ALERTS` unset or set it to `false` during test runs to avoid sending Telegram messages:

```env
SEND_ALERTS=false
```

### How It Works

1. Run the scanner.
2. The scanner saves `scan_results.json`.
3. The scanner generates `alerts.json`.
4. If `SEND_ALERTS=true` and Telegram credentials are present, each active BUY alert is sent to Telegram.

Example:

```bash
cd python-engine
./venv/bin/python scanner.py --limit 50
```

The backend exposes saved alerts at:

```text
GET /api/alerts
```
# Trading Cockpit

## Supported Python

The quantitative engine supports the project dependencies installed in its
virtual environment. IBKR diagnostics specifically require Python 3.11 or
3.12; Python 3.14 is not supported by `ib_insync`.

Create the engine environment with Python 3.12:

```bash
cd python-engine
python3.12 -m venv venv
./venv/bin/pip install -r requirements.txt
```

IBKR remains connection-diagnostic only. It does not place broker orders.
